# Open Ice Finder — icetimes.ca

Drop-in public skating, stick & puck and drop-in hockey times across Metro Vancouver, in one searchable page.

- Live site: https://icetimes.ca
- The page is a single `index.html` with the week's schedule built in. It is refreshed every week from city and rink websites.
- Always confirm a session on the rink's own site before you go.
